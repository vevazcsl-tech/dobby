Política de Privacidade

Dobi — Assistente Pessoal de IA · Última atualização: 23 de outubro de 2026

Resumo: o Dobi é um projeto pessoal de uso privado. Todos os dados são processados no meu próprio equipamento. Nada é vendido, partilhado ou enviado a terceiros para fins comerciais.

1. Quem sou eu

O Dobi é desenvolvido e operado por Walter Manuel do Carmo, em Portugal, como projeto pessoal. Contacto: rogally.dobby@gmail.com.

2. Que dados são tratados

O Dobi funciona exclusivamente com dados do próprio operador (o autor do projeto). Não recolhe dados de terceiros. Concretamente:

2.1 Dados do Gmail

  • Scope utilizado: gmail.readonly (apenas leitura)
  • Dados acedidos: assunto, remetente, data e corpo das mensagens da conta rogally.dobby@gmail.com
  • Finalidade: resumir mensagens importantes e ajudar na organização da agenda pessoal
  • Não é feito: envio, eliminação, modificação ou marcação de mensagens

2.2 Dados de agenda e lembretes

  • Compromissos, tarefas domésticas e datas familiares introduzidos manualmente
  • Guardados em ficheiros locais no equipamento do operador

2.3 Dados de saúde (opcional)

  • Frequência cardíaca, passos e sono provenientes do relógio inteligente pessoal
  • Processados localmente, nunca transmitidos a servidores externos

3. Onde os dados são processados

O Dobi corre num computador pessoal (ASUS ROG Ally com sistema NixOS), na rede doméstica do operador. Os dados são armazenados em ficheiros locais e numa base de dados local.

Para funcionalidades de inteligência artificial, o Dobi pode comunicar com fornecedores de modelos de linguagem (por exemplo, DeepSeek ou modelos locais via Ollama). Nesses casos, apenas o texto estritamente necessário é enviado, e nunca credenciais, tokens de acesso ou dados de identificação.

4. Partilha com terceiros

Não há partilha de dados com terceiros. Os dados não são vendidos, alugados, cedidos nem utilizados para publicidade ou criação de perfis comerciais.

5. Segurança

  • Credenciais OAuth guardadas localmente com permissões restritas
  • Dados sensíveis (credenciais, IBANs) guardados em cofre encriptado
  • Acesso ao equipamento protegido por autenticação do sistema operativo
  • Sem exposição direta à internet — o acesso remoto é feito por rede privada (VPN)

6. Retenção

Os dados são mantidos enquanto o projeto estiver ativo. Podem ser eliminados a qualquer momento pelo operador, bastando apagar os ficheiros locais correspondentes.

7. Direitos do titular

Como o único titular de dados é o próprio operador, os direitos de acesso, retificação, eliminação e portabilidade são exercidos diretamente sobre os ficheiros locais. Para qualquer questão: rogally.dobby@gmail.com.

8. Revogação do acesso ao Google

O acesso à conta Google pode ser revogado a qualquer momento em myaccount.google.com/permissions. A revogação é imediata e impede qualquer acesso futuro.

9. Alterações a esta política

Esta política pode ser atualizada. A data de última atualização está sempre indicada no topo da página.
